# 検討中の設計

ここに置く文書は、調査時点の候補と未実装の設計である。
公開 API として実装した契約は [高レベル API](../HIGH_LEVEL_API.md)、
[低レベル API](../LOW_LEVEL_API.md)、[再生 API](../MEDIA_PLAYOUT.md) を参照すること。

| 文書                                                        | 実装済みの範囲                                               | 検討する範囲                                                                 |
| ----------------------------------------------------------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| [音声の FEC](AUDIO_FEC.md)                                  | Datagram の重複送信と重複排除                                | FEC、時間を空けた冗長送信などの候補と交換条件                                |
| [fill / FETCH による欠落回復](FETCH_GAP_RECOVERY.md)        | 低レベルの FETCH と fill の要求、Object の受信               | 継続購読に対する欠落検出、期限、回復要求、重複排除の統合                     |
| [高レベル API の namespace 告知](NAMESPACE_ANNOUNCEMENT.md) | 低レベル API の `publishNamespace` と `NamespacePublication` | `createMediaPublisher` の `announce`、告知のライフサイクル、実リレーでの検証 |

設計を採用する場合も、現在の既定動作として読み替えない。
実装時にはソースと仕様を確認し直し、実測と API の文書を追加する。
