# Parameter Scope 検証を追加する

- Priority: High
- Created: 2026-06-03
- Model: deepseek-v4-pro
- Branch: feature/draft-18
- Polished: 2026-06-03

## 目的

draft-ietf-moq-transport-18 §10.2.1 (Parameter Scope) は、許可されないコンテキストでパラメータを受信した場合に PROTOCOL_VIOLATION でセッションを閉じることを MUST で要求している。moqt-rs-private には完全な検証実装があるが、moqt-js には一切ない。

## 優先度根拠

仕様の MUST 要件の未実装。誤ったコンテキストでパラメータを受信しても検出されず、プロトコル状態の破綻を招く可能性がある。

## 現状

- moqt-rs-private の `src/message.rs` には `SUBSCRIBE_ALLOWED_PARAMS`、`SUBSCRIBE_OK_ALLOWED_PARAMS`、`REQUEST_OK_ALLOWED_PARAMS`、`PUBLISH_OK_ALLOWED_PARAMS`、`TRACK_STATUS_OK_ALLOWED_PARAMS`、`REQUEST_UPDATE_ALLOWED_PARAMS`、`FETCH_ALLOWED_PARAMS`、`SUBSCRIBE_NAMESPACE_ALLOWED_PARAMS`、`SUBSCRIBE_TRACKS_ALLOWED_PARAMS`、`PUBLISH_NAMESPACE_ALLOWED_PARAMS` 等の完全な検証がある。
- moqt-js には一切のパラメータスコープ検証がない。

draft-ietf-moq-transport-18 §10.2.1:
> An endpoint that receives a parameter in a context where it is not
> allowed MUST close the session with a PROTOCOL_VIOLATION.

## 設計方針

- 各メッセージ種別ごとに許可パラメータ集合を定義する
- 受信時にパラメータ型をチェックし、許可されていない場合は PROTOCOL_VIOLATION でセッションを閉じる
- moqt-rs-private の実装を参考に以下のコンテキストをカバーする:
  - SUBSCRIBE: AUTHORIZATION_TOKEN, OBJECT_DELIVERY_TIMEOUT, SUBGROUP_DELIVERY_TIMEOUT, SUBSCRIBER_PRIORITY, FORWARD, SUBSCRIPTION_FILTER, GROUP_ORDER, NEW_GROUP_REQUEST, RENDEZVOUS_TIMEOUT
  - SUBSCRIBE_OK: EXPIRES, LARGEST_OBJECT
  - REQUEST_OK (PUBLISH_OK): OBJECT_DELIVERY_TIMEOUT, SUBGROUP_DELIVERY_TIMEOUT, SUBSCRIBER_PRIORITY, GROUP_ORDER, SUBSCRIPTION_FILTER, FORWARD, NEW_GROUP_REQUEST, EXPIRES
  - REQUEST_OK (REQUEST_UPDATE_OK): LARGEST_OBJECT
  - REQUEST_OK (TRACK_STATUS_OK): LARGEST_OBJECT
  - REQUEST_OK (SUBSCRIBE_NAMESPACE_OK): (empty)
  - REQUEST_OK (PUBLISH_NAMESPACE_OK): (empty)
  - REQUEST_OK (SUBSCRIBE_TRACKS_OK): (empty)
  - REQUEST_UPDATE (全 context 和集合): AUTHORIZATION_TOKEN, OBJECT_DELIVERY_TIMEOUT, SUBGROUP_DELIVERY_TIMEOUT, SUBSCRIBER_PRIORITY, FORWARD, SUBSCRIPTION_FILTER, NEW_GROUP_REQUEST, TRACK_NAMESPACE_PREFIX
    - REQUEST_UPDATE context 別内訳:
      - SUBSCRIBE context: AUTHORIZATION_TOKEN, OBJECT_DELIVERY_TIMEOUT, SUBGROUP_DELIVERY_TIMEOUT, SUBSCRIBER_PRIORITY, FORWARD, SUBSCRIPTION_FILTER, NEW_GROUP_REQUEST, TRACK_NAMESPACE_PREFIX
      - FETCH context: AUTHORIZATION_TOKEN, SUBSCRIBER_PRIORITY
      - PUBLISH_NAMESPACE context: AUTHORIZATION_TOKEN
      - SUBSCRIBE_NAMESPACE context: AUTHORIZATION_TOKEN, TRACK_NAMESPACE_PREFIX
      - SUBSCRIBE_TRACKS context: AUTHORIZATION_TOKEN, TRACK_NAMESPACE_PREFIX
  - FETCH: AUTHORIZATION_TOKEN, FILL_TIMEOUT, SUBSCRIBER_PRIORITY, GROUP_ORDER
  - FETCH_OK: EXPIRES, LARGEST_OBJECT
  - SUBSCRIBE_NAMESPACE: AUTHORIZATION_TOKEN
  - SUBSCRIBE_TRACKS: AUTHORIZATION_TOKEN
  - PUBLISH_NAMESPACE: AUTHORIZATION_TOKEN

## 完了条件

- 全メッセージコンテキストでパラメータスコープ検証が実装されている
- 許可されていないパラメータ受信時に PROTOCOL_VIOLATION でセッションが閉じられる
- PBT テストが追加されている
